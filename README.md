# DSH Web 后台启动器（任务栏托盘图标）

> **当前版本：v1.1.0**（查看方式：exe 属性 → 详细信息；或 `logs\tray.log` 首行）

在 Windows 后台运行 `npx @deepseek-ai/dsh web` 的启动程序：

- 原生编译 exe（WinForms），**平时无任何窗口**，只有任务栏右下角托盘图标
- **两阶段启动（彻底解决"有更新时无法正常启动"）**：
  1. **阶段 A（更新）**：自动对比本地 dsh 版本与 npm 最新版本（带超时保护），有新版则执行 `npm install -g @deepseek-ai/dsh@最新版` 更新（进度与错误记录到 `logs\dsh-update.log`）；即使更新失败，也会继续用现有版本启动，**绝不会因更新失败而启动不起来**
  2. **阶段 B（启动）**：直接用已安装的 dsh 程序启动服务器（**优先全局 npm 安装，其次 npx 缓存**；`node ...\@deepseek-ai\dsh\lib\bin.js web --port 3080 --no-open`），不联网、不经 npx、不被缓存文件锁/网络问题影响，启动更快更可靠；`--no-open` 避免每次启动重复弹浏览器
- **服务器就绪后终端窗口自动隐藏**，继续后台运行；托盘菜单可随时**显示/隐藏终端窗口**
- 托盘图标：**绿色** = 运行中，**灰色** = 已停止；**左键双击**打开界面 `http://127.0.0.1:3080`
- 右键菜单：打开界面 / 启动 / 重启 / 停止 / 显示或隐藏终端窗口 / 开机自动启动 / 打开日志文件夹 / 退出
- 启动失败会**弹窗显示错误日志末尾**；服务器崩溃时气泡通知并变灰，可一键重启
- 支持开机自启（写入当前用户注册表 `Run` 键）

## 文件说明

| 文件 | 作用 |
| --- | --- |
| **`DshTray.exe`** | **主程序（推荐直接双击它）**：原生托盘程序，不需要 PowerShell |
| `DshTray.cs` | 主程序源码（如需修改可重新编译，见文末） |
| `Start-DshTray.bat` | 便捷启动入口（仅启动 exe；bat 本身会有约 0.1 秒的 cmd 窗口闪现） |
| `logs\` | 运行时自动创建：`dsh-stdout.log`（服务器终端输出）、`dsh-update.log`（版本检查/更新输出）、`tray.log`（托盘操作日志）、`dsh-server.pid`（进程号）、`start-dsh.cmd`（服务器启动脚本）、`update-run.cmd`（更新命令脚本）、`capture.cmd`（版本查询脚本，可查看实际执行的命令） |
| `_archive\` | 与托盘程序无关的历史文件（Playwright 调试记录、页面快照、PPT 设计资料等），保留备查，可随时删除 |

## 使用方法

1. **直接双击 `DshTray.exe`** —— 右下角出现托盘图标；若服务器未运行，会先弹出终端窗口显示"检查更新 → 启动服务器"进度，就绪后自动隐藏。
2. 双击托盘图标即可在浏览器打开 `http://127.0.0.1:3080`（自动附带登录 token，无需手动复制 URL）。
3. 每次开机自动启动：右键托盘图标 → **开机自动启动**（勾选即启用，下次登录自动后台运行）。

> 提示：如果右下角看不到图标，点击任务栏 **「^」**（显示隐藏的图标）即可找到，可拖到常驻区。

## 注意事项

- **端口占用**：默认端口 `3080`。若该端口已有 DSH Web 在运行，托盘显示绿色并提示"已在运行"，不会重复启动；"停止服务器"可结束占用该端口的 node 进程。
- **修改端口**：命令行运行 `DshTray.exe --port 8080`；或在 `DshTray.cs` 中修改默认值后重新编译。
- **首次运行**：如从未运行过 `npx @deepseek-ai/dsh`，首次启动需联网下载依赖，终端窗口会显示下载进度，也可查看 `logs\dsh-stdout.log`。
- **重新编译**（修改源码后）：`C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:winexe /out:DshTray.exe DshTray.cs`

## 常见问题

**Q: 浏览器显示 "dsh web authentication required; reopen the URL printed by dsh web."？**
A: dsh 每次启动都会生成随机登录 token，必须用带 token 的 URL 才能访问。v1.1.0 起托盘"打开界面"和双击图标已自动附带 token；若仍遇到此提示（如服务器是手动启动的），请从 `logs\dsh-stdout.log` 中复制最新一行 `http://127.0.0.1:3080/?token=...` 在浏览器打开。

**Q: 有更新时无法正常启动怎么办？**
A: 新版已根治：**更新和启动完全分离**。启动时终端窗口先显示版本检查/更新（自动对比本地与 npm 最新版本，有新版则 `npm install -g` 更新；进度和错误记录在 `logs\dsh-update.log`）；无论更新成功与否，接下来都会**直接用已装好的 dsh 程序启动服务器**（不联网、不经 npx），所以即使网络不好、更新失败，服务器也一定能启动起来（用旧版本），只是会弹气泡提示"更新未成功，已用现有版本启动"。想手动更新的话，运行 `npm install -g @deepseek-ai/dsh@latest` 即可，或在托盘里"重启服务器"。

**Q: 平时会有黑窗口吗？**
A: 平时没有。仅在启动/更新服务器期间会短暂显示终端窗口（让你看到 npx 进度），服务器就绪后自动隐藏；也可以通过托盘菜单"显示/隐藏终端窗口"随时查看。

**Q: 双击 exe 后没看到图标？**
A: 查看 `logs\tray.log` 是否有报错；确认本机装有 Node.js（`node -v` 有版本号）。

**Q: 如何完全退出？**
A: 右键托盘图标 → 退出托盘。可选"是"（同时停止服务器）或"否"（服务器继续后台运行）。

**Q: 如何取消开机自启？**
A: 右键托盘图标取消勾选"开机自动启动"；或删除注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `DSHWebTray` 键。

**Q: 旧的 PowerShell 版启用过开机自启怎么办？**
A: 新版 exe 启动时会自动检测并把自启项迁移指向 `DshTray.exe`，无需手动处理。
